# K06 住宿登记（酒店 / 民宿 / 派出所）

> 意图：讲清"外国人住哪合法、入住要做哪些登记"。
> 触发：任何有住宿安排的攻略。

## 两条硬规则

1. **酒店**：法律要求酒店在入住时核验并报送外籍住客信息 → 主动出示**护照原件**
   （不要只给复印件）。
2. **民宿 / 朋友家**：外籍人士须在 **24 小时内**到附近派出所办理**临时住宿登记**，
   逾期可能被罚款。

> **重要资质**：并非所有住宿都能接待外籍人士——部分小旅馆/民宿**无涉外资质**。
> 预订前必须确认"可接待外籍"。

## 选址通用原则（首次来华）

```
离地铁站步行 5–10 分钟
周边有连锁国际酒店 / 知名便利店 / 有英文服务的餐厅
避开纯本地老旧居民区（语言与支付都在此断档）
```

## 预订渠道与资质核对

| 渠道 | 是否标注可接待外籍 | 备注 |
|---|---|---|
| 国际 OTA | 通常较可靠 | 但仍需与酒店二次确认 |
| 国内 OTA | 需逐条核对 | 部分房源不接待外籍 |
| 民宿平台 | 高风险 | 必须问清涉外资质与登记流程 |

## 入住 checklist

- [ ] 出示护照原件，确认酒店完成信息报送
- [ ] 拿一张写有**中文地址 + 电话**的酒店卡片
- [ ] 确认 Wi-Fi、前台英文沟通能力
- [ ] 民宿：确认是否需本人去派出所登记

## 需实时检索项

- 各城市可接待外籍的酒店/民宿范围与登记细则 | 各地执行差异 | 属地派出所 / 文旅部门

## 常见关联

- 与 K02（入境准备）、K03（支付）、K11（预算）联动。
