# K11 预算拆解

> 意图：把一次行程的花费拆成可对照的档位表。
> 触发：有预算意图、或行程 ≥ 3 天。

## 通用预算结构（人均，不含国际机票）

| 项目 | 经济档 | 舒适档 | 备注 |
|---|---|---|---|
| 住宿 | 青旅/经济连锁 | 国际五星/精品 | 按晚数折算 |
| 餐饮 | 街头+平价 | 正餐+特色 | 含 1–2 顿特色大餐 |
| 市内交通 | 地铁为主 | 打车+接机 | 含机场往返 |
| 景点门票 | 只买必看 | 联票+讲解 | 淡旺季差价 |
| 城际交通 | 二等座/硬卧 | 一等座/机票 | 跨城时才有 |
| 专项（一日游/包车） | 自助 | 跟团/包车 | 远郊景点 |
| 伴手礼/杂项 | 少 | 多 | 弹性最大 |
| **合计** | — | — | 标注"不含国际机票" |

## 拆分原则

- **给两档**（经济 / 舒适），不给"唯一答案"。
- **区分"固定成本"与"弹性成本"**：门票/交通较固定，伴手礼/餐饮弹性大。
- **省钱开关**：给 3–5 个"想省则省、想升级则升级"的阀门
  （住宿档位 / 高铁席别 / 是否包车 / 吃饭档次 / 是否请讲解）。
- **口径透明**：明确写"仅含 X，不含 Y"，避免误导。

## 按预算档位的常见结构（模板）

| 总预算（X 天） | 建议打法 |
|---|---|
| 低（如 7 天 5000 元） | 单城深耕 + 青旅/经济酒店 + 地铁 + 平价餐饮 + 免费景点为主 |
| 中（如 10 天 10000 元） | 2–3 城 + 经济连锁 + 高铁二等 + 适度正餐 + 必看景点 |
| 高（如 21 天 50000 元） | 多城 + 五星/精品 + 头等/机票 + 特色餐厅 + 包车/私导 |

## 需实时检索项

- 各项实时价格（酒店/门票/车票/餐饮） | 淡旺季与浮动 | 各官方渠道

## 常见关联

- 与 K03（支付）、K06（住宿）、K07（交通）、W6（约束）强联动。
