# K05 语言翻译

> 意图：让"不会中文"的人靠工具与技巧活下来。
> 触发：用户声明不会中文（默认假设）。

## 三层翻译能力

```
第一层  翻译 App（离线段）
        拍照翻译（菜单/路牌）、语音对话、文字输入
第二层  中文小卡片 / 截图
        目的地中文名、酒店中文地址卡、忌口说明卡——比实时语音可靠
第三层  人工
        酒店前台、景区游客中心、商场服务台、使领馆
```

## 高频沟通场景话术（可给拼音）

| 场景 | 表达 |
|---|---|
| 不要辣 | bu yao la / 不辣 |
| 微辣 | wei la / 微辣 |
| 买单 | mai dan / 买单 |
| 我要这个 | zhe ge / 这个 |
| 洗手间在哪 | xi shou jian zai na |
| 帮我叫车 | bang wo jiao che |

## 演示给谁看（重要技巧）

给司机看：让酒店前台写**中文地址小卡片**（全名 + 电话 + 最近地铁口）。
给服务员看：翻译 App 拍照菜单 → 指图片点菜。
给医生看：翻译 App 描述症状 + 过敏史。

## 输出时必须给的

- 翻译 App 推荐与"离线包先下载"提醒。
- 一张"高频场景中文/拼音对照卡"。
- "让酒店写中文卡片"这一兜底技巧。

## 通用知识 vs 实时项

- 翻译 App 名称、离线功能 → `[通用知识]`
- 具体 App 的实时可用性/免费额度 → `[需实时检索确认]`
