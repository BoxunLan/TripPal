# K07 高铁 / 飞机购票证件

> 意图：讲清"外国人拿护照怎么买票、取票、进站、值机"。
> 触发：任何有城际移动的攻略（W2 必加载）。

## 核心事实

- 中国高铁/火车实行**实名制**，外籍旅客凭**护照**购票与进站。
- 12306 官方渠道支持护照注册，但全中文；OTA（如携程国际版）更友好但略贵。
- 购票渠道三条路：**官方 App/网站 → 线下窗口/自助机 → 第三方 OTA**。

## 高铁购票通用流程

```
1. 注册（官方渠道需用护照信息注册并核验）
2. 选车次选座（二等/一等/商务；靠窗/过道）
3. 支付（外卡/移动支付/部分窗口现金）
4. 进站：持护照刷证/走人工通道取票（部分站需换纸质票）
5. 安检 → 检票口 → 站台
```

## 最容易误车的环节

- 站名混淆（如"北京"≠"北京西"≠"北京朝阳"）→ 看清票面站名。
- 取票/验证耗时 → 预留至少 40–60 分钟到站。
- 大站换乘距离长 → 预留充足换乘时间。

## 飞机购票要点

- 国内航班同样实名，值机/安检出示护照。
- 小机场航线季节性强、易取消 → 高原/支线行程要留缓冲日。
- 廉价航司行李额严格，注意尺寸重量。

## 退改签

- 高铁：发车前可退改，越临近手续费越高；开车后一般不可退。
- 航班：按票价规则，特价票退改严格。

## 输出时必须给的

- 三渠道对比表（注册难度/取票便利/价格）。
- "进站五步"与"预留时间"提醒。
- 按人群的购票建议（带娃、老人、行李多）。

## 需实时检索项

- 具体车次/航班时刻与票价 | 调图与浮动 | 12306、航司官网
- 各站取票/进站规则差异 | 车站政策不一 | 12306 客服、车站公告
