# K08 景点预约证件

> 意图：避免"飞到门口被告知约满"的崩盘；讲清外国人怎么用护照预约热门景点。
> 触发：任何含热门景点（故宫/国博/陕历博/莫高窟/布达拉宫/兵马俑等）的攻略。

## 认知框架：为什么现场买不到

```
实名限流（每天设上限，实名+分时段）
免费 ≠ 随便进（免费馆多须预约）
预约集中在线上（官方公众号/小程序/App）
外国人痛点：要微信、要中国手机号、要中文界面
```

## 预约四步法

```
1. 出发前先列"需要预约的景点清单"
2. 逐个查最新预约规则（渠道/放票时间/提前天数/是否分上下午/外宾通道）
3. 用护照信息注册 + 卡点抢票（旺季提前数天，准点放票）
4. 到馆核验：护照原件 + 预约码/二维码
```

## 抢不到票的兜底（关键）

- 换时段（下午场/淡时段）
- 换替代景点（如故宫约不到 → 景山 + 国家博物馆）
- 找酒店前台/游客中心协助
- 关注"当日/滚动放票""退票回流"

## 输出时必须给的

- "最需要提前约的景点"清单表（景点/城市/难度/备注）。
- 预约前必备清单（护照原件、有效期、能收验证码的手机号）。
- 抢不到的三档兜底方案。

## 需实时检索项

- 各景点放票时间、提前天数、预约入口、外宾通道 | 常年调整且旺季秒空 | 各馆官方公众号/官网
