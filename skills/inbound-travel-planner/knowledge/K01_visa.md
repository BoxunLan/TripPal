# K01 签证 / 免签

> 意图：让用户 30 秒内对号入座——"我这本护照 + 我这次来华目的，走哪条路最省事"。
> 触发：首次来华、跨口岸、停留期敏感、任何"能不能不办签证"的疑问。

## 认知框架：四层入境通道（自上而下判断，命中即停）

```
判断 1  互免签证协议 / 中国单方面免签名单        → 免签直接飞
判断 2  只是过境（A 国 → 中国 → B 国）           → 24h / 72h / 144h 过境免签
判断 3  正式入境停留                            → 提前办普通签证（L/M/F/Z/X/Q/S…）
判断 4  外交/公务/APEC/港澳台/永居              → 另外的证件体系（仅提及）
```

## 操作要点

- **免签 ≠ 随便待**：每种免签都有停留天数、活动范围、目的、年度累计天数限制；超期罚款/拘留/限制入境。
- **免签入境边检常查**：返程机票订单、酒店订单、足够旅费、在华联系人——建议打印一份随身带。
- **免签身份不得工作、不得全职读书、不得境内直接变更身份**（须出境后重新申请）。
- **普通签证选错类别是被拒签最常见原因**：旅游用 L、商务考察/会议用 M、交流讲学用 F 等；
  来华"短期帮忙领工资"用旅游签 = 非法就业。
- **名单与天数会扩围调整**：出发前 7 天务必再查官方公告。

## 输出时必须给的

1. 一份"免签类型对比表"（互免/单方面/海南/邮轮/组团/24h/72-144h/APEC）。
2. 一份"普通签证类别对比表"（L/M/F/Z/J/X/Q/S/C/D：适用目的、典型申请人、停留期、能否工作）。
3. 3–5 个"最容易选错的情况"警示。

## 需实时检索项（模板）

- 单方面免签/互免国家名单与停留天数 | 逐年扩围调整 | 中国领事服务网、驻外使领馆官网
- 过境免签适用国籍、口岸、可活动区域 | 口岸名单动态更新 | 国家移民管理局官网
- 各类签证停留期与申请材料 | 使馆口径不定期调整 | 中国签证申请服务中心

- 与 K02（入境准备）、W7（特殊入境方式）联动。
