# K09 餐饮英文服务 / 过敏忌口

> 意图：解决"没有英文菜单、吃不了辣、有过敏忌口"的点餐难题。
> 触发：几乎每一篇攻略都加载。

## 点餐三招

```
招 1  看邻桌指菜："this one"
招 2  翻译 App 拍照菜单 → 指图片点
招 3  App 搜餐厅（评分/招牌菜图片）给服务员看
```

## 通用tips

- 辣度：川湘渝默认辣 → 说"不辣/微辣"（bu la / wei la）。
- 饮水：自来水不直饮；餐厅默认上热水，要冰水说"ice water"。
- 小费：中国无小费文化，不用给。
- 叫服务员：招手或喊"服务员"，不会主动来倒水。

## 特殊饮食分支

| 需求 | 策略 |
|---|---|
| 素食 | 明确说"vegetarian / 不吃肉"；寺院素斋、部分连锁可选 |
| 清真 | 找清真餐厅/清真标识；部分地区（如牛街、西北）选择多 |
| 洁食（Jewish kosher） | 极稀缺，需提前做功课或自带/联系社区 |
| 过敏（坚果/海鲜/麸质） | 用翻译 App 写清过敏原卡给服务员看；随身带药 |

## 输出时必须给的

- "无英文菜单怎么点"的三招。
- 辣度/忌口的中文话术卡。
- 按饮食禁忌分类的就餐策略。

## 需实时检索项

- 具体餐厅的营业/评分/是否清真 | 常变 | 点评类 App
- 清真/素食/洁食餐厅分布 | 各地差异 | 本地社区与点评 App
