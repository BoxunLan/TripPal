# K04 手机卡 / eSIM / 上网 / 网络合规

> 意图：解决"落地后怎么上网、用什么卡、哪些 App 用不了"。
> 触发：天数 ≥ 3、或用户提到通讯/上网/网络。

## 三条上网路线

| 方案 | 适合 | 要点 |
|---|---|---|
| **国际漫游** | 短期、图省事 | 出发地运营商开通；费用较高，远郊信号可能掉 |
| **本地物理 SIM** | 停留 ≥ 7 天 | 机场/营业厅购买，需护照实名，装卡即用 |
| **eSIM** | 支持 eSIM 的机型 | 出发前线上购买，落地激活，无需实体卡 |

> **通用兜底**：酒店/商场/咖啡馆 Wi-Fi 到处有；但景区 Wi-Fi 不稳，别用来做支付。

## 网络合规（必须如实说明）

- 中国大陆无法直接访问部分海外应用与服务；**不要轻信街头"卖 VPN"的人**。
- 给家人报平安：提前约定用可用的通讯方式（如微信、邮件、酒店电话）。
- 涉及翻墙的内容一律按合规口径提醒，不提供规避方法。

## 落地第一天通讯 setup

```
1. 连酒店 Wi-Fi 给家人报平安
2. 决定用漫游还是装本地卡（看停留天数）
3. 存好打车/地图/翻译 App，确认能离线用
4. 记住紧急电话（见 K10）
```

## 输出时必须给的

- 三方案对比表（费用/便利/适合天数）。
- "落地 30 分钟通讯 setup"清单。
- 网络合规说明（中性、不猎奇）。

## 需实时检索项

- 本地短期 SIM / eSIM 套餐资费 | 运营商套餐频繁变动 | 三大运营商官网
- 漫游资费 | 按目的地不同 | 出发地运营商
- 可访问的海外服务清单 | 服务可用性动态变化 | 无需给具体名单，仅提示以当地实际情况为准

## 常见关联

- 与 K03（移动支付，需手机号）、K05（翻译 App）、K10（应急）联动。
