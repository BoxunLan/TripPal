# K03 外卡支付与支付宝 / 微信绑定

> 意图：讲清"外卡能在哪刷、移动支付怎么绑、绑不上怎么办"。
> 触发：几乎每一篇攻略都加载（这是外国人第一痛点）。

## 认知框架：三轨支付

```
轨道 A  实体外卡（VISA/MasterCard/JCB/Amex）
        大型商场/连锁酒店/连锁餐厅/老字号 → 可刷
        地铁/公交/出租/街边小馆/公园售票/景区小卖部 → 不能刷

轨道 B  移动支付（支付宝 / 微信）
        支持绑定部分境外卡，有汇率优势；需注册+实名+（常需）中国手机号验证

轨道 C  现金（人民币）
        万能兜底，但需提前换好
```

## 判定分支

- 停留 ≤ 5 天：**不强推绑定移动支付**，现金 + 外卡组合更省心。
- 停留 ≥ 7 天 / 深度游：值得花时间绑一个（支付宝国际版优先）。
- 无中国手机号：多数渠道卡在验证码环节 → 走现金轨。

## 绑定通用步骤（支付宝 / 微信）

```
1. 下载正确的"国际版/境外用户"入口
2. 用邮箱/境外手机号注册
3. 完成"外国用户实名"（护照 + 人脸/信息核验）
4. 绑定境外银行卡（按提示逐项填）
5. 绑完做小额测试（便利店/自动售货机）验证通路
6. 设置支付密码、开启安全锁
```

## 常见错误与应对

| 现象 | 原因 | 应对 |
|---|---|---|
| 绑卡失败 | 卡组织不支持 / 信息不符 | 换一张卡 / 核对姓名拼写与护照一致 |
| 收不到验证码 | 无中国号 / 境外号漫游不稳 | 用 Wi-Fi 重试 / 改走现金 |
| 扫码后付款失败 | 商户码不支持外卡渠道 | 换现金 / 换下一家 |
| 街边店扫不了 | 商户只收国内渠道 | 备零钱 |
