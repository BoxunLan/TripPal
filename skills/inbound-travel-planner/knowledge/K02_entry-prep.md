# K02 入境准备（行前清单 + 边检海关）

> 意图：把"出发前必须搞定的 N 件事"和"落地后的入境流程"讲清。
> 触发：几乎每一篇攻略都加载。

## 行前必做（通用清单模板）

1. **确认签证/免签身份**（见 K01）。
2. **打印两份行程单 + 酒店预订单**：英文版 + 中文版各一份，边检/酒店都用得上。
3. **换少量人民币现金**：建议 1500–2000 元零钞，用于地铁/小店/景区小卖部。
4. **下载三个离线可用 App**：地图（离线包）、翻译（离线中文包）、打车/乘车码（视需求）。
5. **准备外卡主卡 + 备用卡**：VISA/MasterCard 为主，JCB/Amex 备用（防 POS 不识别）。
6. **存使领馆电话**：纸质 + 手机各一份。
7. **提前预约热门景点**（见 K08）。

## 边检 / 海关通用流程

```
下机 → 跟 Arrivals/到达 标识（别跟 Transit）→ 边检递护照+入境卡+回程机票+酒店单
     → 边检可能英文问"来干嘛/待几天/住哪"，如实答 → 取行李 → 海关无申报通道
```

## 海关申报与违禁品（要点）

- 现金超等值一定金额须申报；带贵重设备、处方药、宠物另有专门规则（见 W7）。
- 违禁/限制品：濒危动植物制品、部分肉类乳制品、超量烟酒、部分种子等。
- **不要替陌生人带东西**——这是最常见的入境陷阱。

## 落地第一天常见故障（兜底）

| 故障 | 兜底 |
|---|---|
| 边检英文听不懂 | 说"Sorry, could you speak slowly?"；拿不准就示意需要翻译/指后面的人 |
| 入境卡不会填 | 用翻译 App 问空乘或边检，如实填，不确定留空 |
| 行李延误 | 到航司行李查询柜台登记，留酒店地址让航司直送 |

## 需实时检索项

- 免签/过境政策细则 | 政策动态 | 移民管理局
- 海关免税额度与申报门槛 | 规定调整 | 海关总署
- 违禁品清单更新 | 名录调整 | 海关总署
