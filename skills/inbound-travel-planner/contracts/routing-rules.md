# 路由规则（Routing Rules）

> 定义"用户输入 → 意图 → 工作流"的判定边界、复合叠加规则与追问策略。

---

## 一、输入解析：先抽取 8 个槽位

任何请求先解析成结构化字段，再路由：

| 槽位 | 取值示例 | 用途 |
|---|---|---|
| `地点` | 北京 / 北京-西安-上海 / 中国（无具体城市） | 判 W1 vs W2 |
| `天数` | 3 / 5 / 10 / 30 | 判 W1/W2/W6 |
| `人群` | 老人 / 亲子 / 残障 / 素食 / 穆斯林 / 背包客 / 独行女性 / 数字游民… | 判 W4 |
| `主题` | 美食 / 博物馆 / 古镇 / 徒步 / 摄影 / 非遗… | 判 W3 |
| `预算` | 5000 元 / 无 | 判 W6 |
| `季节/节假` | 春 / 夏 / 春节 / 国庆 / 寒假… | 判 W6 |
| `入境/交通方式` | 邮轮 / 陆路口岸 / 转机 / 自驾 / 大巴 / 宠物 / 处方药… | 判 W7 |
| `对比项` | A vs B | 判 W8 |

## 二、判定优先级（冲突时的取舍）

```
W8 对比 / W5 实务 / W7 特殊   ← 最高优先（语义极明确，直接命中）
        ↑
W4 人群 / W3 主题             ← 次高（强修饰信号）
        ↑
W6 约束（预算/季节/天数）      ← 中等
        ↑
W2 跨城 / W1 单城             ← 兜底（有行程但无其他强信号）

都不命中 → 默认 W1，并要求澄清
```

**关键规则：**

1. **"如何……"句式优先判 W5**，哪怕句中出现城市。
   - "外国人在北京如何订高铁票" → **W5**（不是 W1）。
2. **"选哪个 / vs / 还是"优先判 W8。**
3. **人群/主题信号强于城市信号**：先套 W4/W3 骨架，城市作为填充参数。
4. **预算/季节是修饰，不是独立工作流**，除非用户**只**给约束不给地点
   （"中国 7 天预算 5000 元" → 主 W6）。

## 三、复合意图叠加矩阵

主工作流决定"整体叙事骨架"，修饰工作流决定"某几章换成什么角度"。

| 主 \ 修饰 | W4 人群 | W6 约束 | W7 特殊 | W3 主题 |
|---|---|---|---|---|
| **W1 单城** | 逐日行程按人群节奏改写；追加人群专属章 | 逐日按预算档位改写；追加省钱开关章 | 追加证件/入境特别通道章 | 单城内部按主题模块组织 |
| **W2 跨城** | 每段城市追加人群适配 | 城际交通降本（高铁二等/夜间车） | 首末城市叠加入境方式 | 跨城按主题串联 |
| **W3 主题** | 主题内追加人群适配 | 主题内追加预算拆解 | — | — |

**示例拆解：**
- "外国残障人士（轮椅）中国 10 天无障碍攻略"
  → 主 **W4**，修饰 **W1**；强加载 K12（无障碍）、K07（交通可达性）、K06（无障碍房型）。
- "外国人在西藏拉萨 5 天 4 晚攻略（含入藏函）"
  → 主 **W1**，修饰 **W7**（入藏函 = 特殊证件通道）；强加载 K01、K07。
- "成都-九寨沟-黄龙 6 天 5 晚"
  → 主 **W2**（跨城）；注意九寨/黄龙属高海拔，追加 K12 + K10。

## 四、追问策略（何时问、何时不问）

**先给"泛化底稿"，再把不确定项列进第五节，不要一上来就卡住问。**

| 情形 | 处理 |
|---|---|
| 国籍缺失 | 不追问，按"免签 / 签证两种情况都覆盖"写，列入缺失项 |
| 出行月份缺失 | 不追问，按四季分别给调整提示，列入缺失项 |
| 同行人/预算缺失 | 不追问，给"经济档 / 舒适档"两档，列入缺失项 |
| 抵离城市缺失 | 默认一个最常见方案并声明，列入缺失项 |
| 完全无法判断意图 | 用 AskUserQuestion 问 1 个问题（二选一），不要在开放式上纠缠 |

> **原则：能兜底就不拦截；把"需要用户确认的"变成产出的一部分，而不是前置阻塞。**

## 五、批量任务的附加规则

当用户一次性请求多篇攻略（批量生成模式）时：

1. 按编号顺序逐篇生成，**每篇独立文件**，文件名 `{编号}_{简短主题}.md`。
2. 逐篇完成即可回复进度，不中途询问是否继续。
3. 全部完成后，额外产出：
   - `00_总索引.md`：编号 / 主题 / 文件名 / 完成状态；
   - `99_覆盖分析表.md`：逐题已覆盖模块、弱覆盖模块、需实时检索项、缺失项，
     并在开头给**总体覆盖统计**（每个模块的覆盖率）。
4. 单次输出长度受限时，分批写盘，每批 5–10 篇。
5. 每篇仍**必须**走 contracts/output-contract.md 的完整五段式，不得因批量而缩水。
