# 中英对照高频短语卡

> 用法：在"语言翻译""餐饮""交通"章节中，直接取用本表生成"给司机/服务员/医生看"的话术卡。
> 建议用户**截图保存**，比实时语音更可靠。

## 一、生存必备

| 中文 | 拼音 | English |
|---|---|---|
| 你好 | nǐ hǎo | Hello |
| 谢谢 | xiè xie | Thank you |
| 对不起 / 不好意思 | duì bu qǐ / bù hǎo yì si | Sorry / Excuse me |
| 是 / 不是 | shì / bú shì | Yes / No |
| 我不懂中文 | wǒ bù dǒng zhōng wén | I don't speak Chinese |
| 你会说英语吗 | nǐ huì shuō yīng yǔ ma | Do you speak English? |
| 请说慢一点 | qǐng shuō màn yì diǎn | Please speak more slowly |
| 多少钱 | duō shao qián | How much? |

## 二、交通出行

| 中文 | 拼音 | English |
|---|---|---|
| 我要去这里 | wǒ yào qù zhè lǐ | I want to go here |
| 请打表 | qǐng dǎ biǎo | Please use the meter |
| 请在这里停 | qǐng zài zhè lǐ tíng | Please stop here |
| 地铁站在哪里 | dì tiě zhàn zài nǎ lǐ | Where is the metro station? |
| 火车站 | huǒ chē zhàn | Train station |
| 机场 | jī chǎng | Airport |
| 请帮我叫一辆车 | qǐng bāng wǒ jiào yí liàng chē | Please call a taxi for me |

## 三、点餐用餐

| 中文 | 拼音 | English |
|---|---|---|
| 菜单 / 英文菜单 | cài dān / yīng wén cài dān | Menu / English menu |
| 不要辣 | bú yào là | Not spicy |
| 微辣 | wēi là | Mildly spicy |
| 我不吃肉 | wǒ bù chī ròu | I don't eat meat |
| 我吃素 | wǒ chī sù | I'm vegetarian |
| 我对……过敏 | wǒ duì …… guò mǐn | I'm allergic to … |
| 不要放…… | bú yào fàng …… | No ……, please |
| 买单 / 结账 | mǎi dān / jié zhàng | The bill, please |
| 打包 | dǎ bāo | To go / Doggy bag |
| 冰水 / 热水 | bīng shuǐ / rè shuǐ | Ice water / Hot water |

## 四、住宿与支付

| 中文 | 拼音 | English |
|---|---|---|
| 我要办理入住 | wǒ yào bàn lǐ rù zhù | I'd like to check in |
| 我的预订名字是…… | wǒ de yù dìng míng zi shì …… | My reservation is under … |
| 我可以刷卡吗 | wǒ kě yǐ shuā kǎ ma | Can I pay by card? |
| 可以扫码吗 | kě yǐ sǎo mǎ ma | Can I pay by QR code? |
| 可以用护照吗 | kě yǐ yòng hù zhào ma | Can I use my passport? |
| 洗手间在哪里 | xǐ shǒu jiān zài nǎ lǐ | Where is the restroom? |
| 无线网络密码是多少 | wú xiàn wǎng luò mì mǎ shì duō shao | What's the Wi-Fi password? |

## 五、应急求助

| 中文 | 拼音 | English |
|---|---|---|
| 救命 | jiù mìng | Help! |
| 我需要医生 | wǒ xū yào yī shēng | I need a doctor |
| 我丢了护照 | wǒ diū le hù zhào | I lost my passport |
| 请报警 | qǐng bào jǐng | Please call the police |
| 医院在哪里 | yī yuàn zài nǎ lǐ | Where is the hospital? |
| 请帮我联系大使馆 | qǐng bāng wǒ lián xì dà shǐ guǎn | Please help me contact my embassy |

## 六、给用户的用法建议

- 把本表保存为手机截图，或让酒店前台写成**中文小卡片**。
- 给司机看目的地时，优先出示**中文地址卡**（酒店名 + 电话 + 最近地铁口），不要用实时语音。
- 给医生看症状时，出示翻译 App 生成的文字说明 + 过敏史，比口述更准。
