# 紧急号码与求助渠道速查

> 用法：任何攻略的"安全应急"章节可直接引用本表。号码为长期稳定的通用信息；
> 各城市涉外服务热线、使领馆具体信息以官方实时为准。

## 一、全国统一紧急号码

| 号码 | 用途 | 语言 |
|---|---|---|
| **110** | 报警（治安、刑事、失窃） | 普通话为主 |
| **120** | 急救（医疗救护） | 普通话为主 |
| **119** | 火警 / 消防救援 | 普通话为主 |
| **122** | 交通事故报警 | 普通话为主 |
| **12308** | 中国外交部全球领事保护与服务应急热线 | 多语种，24 小时 |
| **12345** | 政务服务便民热线（可转各类求助） | 普通话为主，部分城市有英文 |
| **12301 / 12315** | 旅游服务热线 / 消费者投诉 | 普通话为主 |

> 提示：报警说不清中文时，可先说明 "English, please"，或到就近的**派出所**当面处理。
> 部分涉外城市（北京、上海、广州等）设有**英语报警坐席**，但覆盖与时段需实时确认。

## 二、就医求助

| 渠道 | 适用 | 说明 |
|---|---|---|
| 连锁药店 | 轻症、常用药 | 用翻译 App 说明症状，可买非处方药 |
| 三甲医院国际部 / 涉外门诊 | 需正规就诊 | 有英文服务，费用较高，出诊时间需确认 |
| 120 急救 | 危重 | 直接拨打，说明位置 |

> 建议随身：个人常用处方药 + 英文处方说明（见 `workflows/W7_special-entry.md` 药品分支）。

## 三、护照 / 财物丢失处理步骤

```
1. 就近派出所报案 → 索取《报案回执》（办证/索赔都要用）
2. 联系本国驻华使领馆 → 补办护照或旅行证
3. 到出入境管理部门补办签证/停留证件
4. 通知保险公司与银行（挂失卡片）
```

> 全流程通常需数个工作日，务必预留时间，不要安排在离境前一天。

## 四、使领馆信息（自查渠道）

- 本国驻华大使馆官网（地址、电话、领保值班手机、办公时间）。
- 驻各城市总领事馆官网（若行程覆盖多个城市）。
- 中国外交部领事服务网 / 12308 热线。

> **本 Skill 不缓存具体使领馆地址电话**——请用户行前自行抄录本国驻华使领馆的
> 24 小时领保电话，并做纸质备份。
