# 礼仪、禁忌与文化差异

> 用法：所有攻略的"文化差异与礼仪提醒""避坑提醒"章节可直接引用。
> 本表偏保守——目的是让外国游客**不冒犯、不吃亏**，而非穷尽所有文化细节。

## 一、总原则（一句话）

**不给小费、不主动肢体接触、公共场合不指望安静、拍照前先示意、办事优先找穿制服的或柜台。**
中国社会节奏快、规则以"效率"为先，很多让外国人不适的场景（插队、大声说话、挤地铁）
并非针对个人，保持冷静即可。

## 二、给小费

| 场景 | 是否需要小费 |
|---|---|
| 餐厅 | 不需要（部分账单含服务费，付账单即可） |
| 酒店 | 不需要 |
| 出租车 | 不需要，按表付费 |
| 导游 / 司机（包车） | 非必需，满意可给，但不是惯例 |
| 行李搬运 | 非必需 |

> 中国**没有小费文化**，给现金小费可能让对方困惑甚至尴尬。

## 三、餐桌礼仪

- 筷子**不要插在米饭上**（形似祭奠，极忌），不要用筷子敲碗。
- 主人给你夹菜是热情，不习惯可婉拒说"谢谢，我自己来"。
- 转盘菜（圆桌）等主宾先动筷。
- 喝热水的习惯很普遍，要冰水主动说 "ice water"。
- 别人敬酒时，不喝酒可用茶代替，无需勉强。

## 四、社交与称呼

- 递名片、递物、接物用**双手**（单手递接较随意，但双手更礼貌）。
- 点头、微笑、握手是常见问候；拥抱贴面不常见。
- 对长辈、服务人员多用"请""谢谢"。
- 遇到围观或拍照，礼貌微笑即可，不想被拍可摆手。

## 五、拍照禁忌

- 天安门、中南海、军事设施、部分边境口岸**不要随意拍摄**。
- 拍当地人（尤其老人、僧人、街头艺人、少数民族）**先微笑示意**，对方摆手就放弃。
- 博物馆、寺庙室内、部分展品**禁止拍照**，看指示牌。
- 寺庙内不要对着佛像近距离闪光拍摄。

## 六、宗教场所（寺庙/道观/清真寺）

- 着装得体，不穿过于暴露的衣物。
- 不喧哗、不踩门槛、不乱动供品。
- 香火/供养遵循现场指引，不轻信"高价开光"。
- 清真寺参观遵守礼拜时间限制。

## 七、公共场所

- 排队文化较弱，高峰时可能有人插队；**不建议正面冲突**，可找工作人员。
- 公共场合音量普遍较大，是常态而非针对。
- 地铁、景区、商场普遍有安检，配合即可（包过机、人走门）。
- 商场普遍 22:00 前后关门，便利店、快餐、部分超市更晚。

## 八、购物与砍价

- 大型商场、连锁店、便利店**明码标价，不砍价**。
- 旅游纪念品市场、部分文玩街可议价，幅度看品类。
- 谨防"低价一日游"带购物店、"免费领礼品"等套路。
- 索要发票/收据，离境退税需凭据（见 `knowledge/K10_safety.md`）。

## 九、吸烟饮酒

- 室内公共场所、地铁、景区多**禁烟**，有专门吸烟区。
- 酒驾零容忍；劝酒文化在减少，可礼貌拒绝。

## 十、给用户的"避坑口诀"

> **不贪便宜（低价团/黑车），不替陌生人带东西（机场），不轻信街头推销（VPN/换汇/开光），
> 拍照先示意，办事找柜台，遇到麻烦打 110 或找酒店前台。**

## 十一、常见"误解"澄清（给外国游客）

| 误解 | 实际情况 |
|---|---|
| "中国很方便，到处能刷卡" | 街边小店、地铁、部分景点只收现金或移动支付 |
| "免签就能待很久" | 免签有停留天数与活动范围限制，超期有处罚 |
| "博物馆免费就能进" | 多数需提前实名预约，免费 ≠ 直接进 |
| "到处都能说英语" | 市中心涉外区可，老城区/远郊基本靠翻译 App |
| "给点小费服务会更好" | 中国没有小费文化，反而不必 |
