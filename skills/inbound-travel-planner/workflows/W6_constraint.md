# W6 约束条件规划（预算 / 天数 / 季节）

> 命中信号：硬约束——预算 X 元 / 只有 N 天短途 / 某季节 / 春节国庆寒假暑假。
> 判定：**只有约束、没有具体城市时，主工作流才是 W6**；
> 有城市时，W6 作为**修饰**叠在 W1/W2 上。
> 底层逻辑：**先讲清约束边界，再用约束反推行程结构。**

## 三种约束，三套解法

### A. 预算约束（如"7 天 5000 元"）

```
### 一、先把预算的"硬边界"讲清楚（含什么、不含什么）
### 二、为什么选这条线（在预算内最大化体验）
### 三、逐日行程
### 四、预算约束下的支付与现金策略
### 五、住宿：该价位怎么选
### 六、餐饮：该日预算怎么吃
### 七、省钱 vs 升级开关
### 八、可替换的同类城市/方案
### 九、检查清单
```

### B. 天数/短途约束（如"3 天上海周边"、"5 天北京周边"）

```
### 一、N 天能去哪、不能去哪（半径与取舍）
### 二、推荐线路（1–2 条）
### 三、逐日行程（紧凑但留机动）
### 四、往返交通
### 五、住宿与打包（短途轻装）
### 六、检查清单
```

### C. 季节/节假日约束（如"春季 14 天"、"国庆避坑"）

```
### 一、这个季节/假期中国是什么样的（气候+人流+价格）
### 二、按季节选线（南方避寒/北方避暑/看花看雪）
### 三、逐日行程（随季节调整节奏与景点）
### 四、季节专属装备与安全
### 五、节假日避坑（抢票/涨价/限流/闭馆）
### 六、检查清单
```

## 核心方法

- **约束先行**：先算出"预算/天数/季节"给的上限与下限，再排行程。
- **给"省钱/升级开关"**：把弹性项列成可切换的阀门（住宿档、席别、是否包车）。
- **节假日专项**：黄金周/春节/寒假——抢票、涨价、限流、部分店铺歇业，
  必须单独成节警示。
- **可替换清单**：同预算/同季节的替代目的地，给用户选择权。
