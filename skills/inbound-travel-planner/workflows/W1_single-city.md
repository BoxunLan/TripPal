# W1 单点城市 / 区域行程

> 命中信号：单一城市或紧密城市群 + 天数（如"北京 5 天 4 晚"、"上海 4 天 3 晚含迪士尼"）。
> 底层逻辑：**一个城市 = 一条"抵达 → 安顿 → 逐日 → 生存 → 离开"的主线。**

## 章节骨架（按此顺序写）

```
### 一、出发前必须搞定的 N 件事            ← 摘 K01/K02/K03/K08
### 二、抵达：从机场/车站到市区            ← 交通方式对比（快轨/出租/接机）
### 三、住哪里：首次来华的安全选择         ← K06 选址原则 + 推荐 2–3 个区域
### 四、{天数} 逐日行程                     ← 核心：Day 1 … Day N
### 五、市内交通与支付生存指南             ← 地铁/打车/外卡能刷范围
### 六、餐饮生存指南                        ← K09
### 七、安全与应急                          ← K10
### 八、预算参考表（两档）                  ← K11
### 九、出发前/抵达后检查清单
### 十、文化差异与礼仪提醒
（可选）十一、常见故障排查 Top 10
（可选）十二、按季节调整
```

## 逐日行程的写法（核心）

- `#### Day N：{主题}（体力标签）`
- 每条用 **上午 / 中午 / 下午 / 傍晚 / 晚上** 分段。
- 每个景点写清：**要不要预约、怎么去、看点、体力消耗、兜底**。
- Day 1 默认轻量（适应时差）；累的日子后接轻松的日子。
- 把"需要提前预约"的景点在**出发前**就标出来。
- 远郊景点（长城/迪士尼）单独占一整天，写清交通方案 A/B/C。

## 必加载知识模块

`K01 K02 K03 K06 K08 K09 K10 K11`（K04/K05/K07/K12 按需）。

## 常见变体

- 含主题词（迪士尼/熊猫）→ 叠 W3 的"主题模块"写法。
- 含人群（带娃/老人）→ 叠 W4 的"人群专属章"。
- 含特殊证件（入藏函）→ 叠 W7 的"证件特别通道"。
- 度假型（三亚）→ 弱化景点预约，强化住宿/餐饮/休闲。

## 质检

- [ ] Day 数与天数一致
- [ ] 每个高风险景点都有"预约提醒 + 兜底"
- [ ] Day 1 是轻量日
- [ ] 有预算两档表
