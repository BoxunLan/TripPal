# W7 特殊入境与交通方式

> 命中信号：非默认入境或交通——邮轮 / 陆路口岸 / 转机 / 多次入境 /
> 商务签转旅游 / 带处方药 / 带贵重设备 / 带宠物 / 自驾(国际驾照) /
> 共享单车 / 长途大巴 / 普速火车。
> 底层逻辑：**先判断"你属于哪种情况"（决策树），再按类型分述。**

## 章节骨架

```
### 一、先做判断：你属于哪种情况（决策树）
### 二、按类型分述：
        类型 A：条件 / 准备 / 流程 / 坑
        类型 B：……
### 三、完整时间轴（以转机/邮轮等时间敏感场景为主）
### 四、最容易踩的 N 个坑
### 五、应急（误机/证件问题/突发）
### 六、检查清单
```

## 各场景的关键判定与要点

| 场景 | 关键判定 | 核心要点 |
|---|---|---|
| **邮轮入境** | 邮轮免签申报 | 由船方统一申报、岸上观光时效、返船时间 |
| **陆路口岸** | 福田/拱北/满洲里等 | 口岸通关时间、跨境证件、接驳交通 |
| **转机 12 小时** | **能不能出机场**（签证/免签/时间窗） | 行李处置、出/入机场时间轴、就近玩点、误机改签 |
| **多次入境签证** | 每次停留期与累计天数 | 别超期、别误当"可长期待" |
| **商务签转旅游** | 能不能境内转 | 通常需出境重办；别非法就业 |
| **带处方药** | 是否含管制成分 | 英文处方 + 原包装 + 申报；精神类/麻醉类另有限制 |
| **带贵重设备** | 是否需申报 | 出境时申报以免被当新增物品征税 |
| **带宠物** | 检疫要求 | 检疫证书、疫苗、隔离规则、提前天数 |
| **自驾/国际驾照** | **中国不承认国际驾照** | 需中国临时驾照或境内租车带司机 |
| **共享单车** | 需 App + 实名 | 无中国号难用；走现金/人工租借兜底 |
| **长途大巴** | 购票与实名 | 站点分散、需护照、班次少 |
| **普速火车/绿皮车** | 与高铁的区别 | 更慢更便宜、卧铺种类、体验向 |

## 写作要点

- **决策树先行**：这类问题的价值在"帮用户判断自己属于哪种情况"。
- **时间敏感场景给"完整时间轴"**（转机、邮轮）。
- **合规红线要讲硬**：国际驾照、无人机、处方药、宠物——一句话讲清合规边界。
- **兜底**：证件/时间出问题时的应急方案。
