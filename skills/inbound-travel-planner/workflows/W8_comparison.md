# W8 决策对比（A vs B）

> 命中信号："A vs B" / "选哪个" / "怎么选"（北京vs上海、西安vs洛阳、
> 成都vs重庆、跟团vs自由行、高铁vs飞机、酒店vs民宿、支付宝vs微信vs现金、
> 免签vs签证、旺季vs淡季、一线vs二三线）。
> 底层逻辑：**不替用户拍板，而是摊开维度 + 按人群给建议。**

## 章节骨架

```
### 一、先一句话结论（关键：先给判断，再讲理由）
### 二、总对比表（一张表摊开所有维度）
### 三、{维度 1}（文化/美食/交通/预算/语言…）
### 四、{维度 2}
### ...
### N-2、分人群决策建议（"如果你是 X，就选 Y"）
### N-1、组合策略（两者都要 / 混合方案）
### N、避坑提醒
### N+1、出发前检查清单
```

## 写作要点

- **先结论后展开**：第一节一句话给判断，避免"看完全文还不知道选谁"。
- **总对比表是核心**：用一张 Markdown 表把 8–10 个维度一次性摊开。
- **中立**：不贬低任何一方，讲清"什么人该选什么"。
- **分人群建议**：历史迷→A，都市控→B；体力弱→A，预算紧→B……
- **给组合/混合方案**：很多对比的正确答案是"都要"或"混合"
  （如"自由行为主 + 远途一日游跟团"）。
- **地域类对比**（如"一线 vs 二三线"）→ 按梯队分类 + 分梯队清单。

## 常见对比的维度模板

| 对比类型 | 核心维度 |
|---|---|
| 城市 vs 城市 | 气质/景观/美食/气候/步行强度/英语友好度/外卡友好度/预算/适合人群 |
| 方式 vs 方式（跟团/自由行） | 成本/自由度/语言门槛/踩坑风险/适合人群/混合方案 |
| 交通 vs 交通（高铁/飞机） | 耗时/价格/准点/行李/站点位置/适合距离 |
| 支付 vs 支付 | 覆盖面/门槛/汇率/适用场景/兜底 |
| 政策 vs 政策（免签/签证） | 门槛/停留期/灵活性/风险 |
| 季节 vs 季节 | 气候/人流/价格/景观/适合活动 |

## 必加载知识模块

按对比对象取 2–4 个（城市对比→K03/K07/K11/K12；支付对比→K03；政策对比→K01）。

## 质检

- [ ] 第一节给了明确倾向（或明确"视人群而定"）
- [ ] 总对比表维度 ≥ 8 行
- [ ] 有分人群建议
- [ ] 有组合/混合方案
- [ ] 中立不贬低
