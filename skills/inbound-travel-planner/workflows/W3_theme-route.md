# W3 主题深度线路

> 命中信号：出现主题词——美食 / 博物馆 / 古镇 / 茶 / 功夫太极 / 中医 / 非遗 /
> 摄影 / 徒步 / 骑行 / 高铁 / 大运河 / 丝路 / 熊猫 / 少数民族 / 佛教名山 /
> 道教名山 / 红色旅游 / 工业遗产 / 当代建筑。
> 底层逻辑：**一条主题线 = "这条线在讲什么" + 按主题模块（不是按城市）串联。**

## 章节骨架

```
### 一、行前总览：这条线到底在讲什么        ← 主题的定义与看点
### 二、{主题}视角的签证/支付/通讯特别提醒   ← 主题特有的实务
### 三、{主题模块 1}（Day a–b）
### 四、{主题模块 2}（Day c–d）
### ...
### N-3、{主题}必体验清单（必吃/必看/必做）  ← 按主题组织，不按城市
### N-2、预算拆解
### N-1、行李清单（主题特别版）
### N、文化/礼仪/避坑提醒
### N+1、检查清单
```

## 编排原则

- **按"体验单元"切分，而非按城市**：美食专题按"城市风味块"，摄影专题按"机位/季节"，
  徒步专题按"路段难度"，骑行专题按"路线天数"。
- **每个模块给"门槛与准备"**：主题游往往有专业门槛（徒步要装备、摄影要季节、
  茶要产区知识、功夫要预约课程）。
- **主题清单是灵魂**：结尾必须有一张"按主题整理的必体验清单"。

## 典型主题的特殊要求

| 主题 | 必须额外讲 |
|---|---|
| 美食 | 必吃清单 + 辣度/忌口沟通 + 食品安全 |
| 博物馆 | 预约（K08）+ 讲解/英文导览 + 闭馆日 |
| 徒步/骑行 | 装备、体力分级、季节窗口、安全（K12/K10） |
| 摄影/无人机 | 机位、黄金时段、无人机法规（见 W7） |
| 茶/非遗/中医 | 体验课程预约、产区/工作室分布 |
| 宗教名山 | 礼仪禁忌、香火/供养常识 |
| 红色旅游 | 讲解预约、场馆规范 |

## 必加载知识模块

`K02 K03 K09 K11` + 主题对应模块（摄影→K12/K07；徒步→K12/K10；博物馆→K08）。
