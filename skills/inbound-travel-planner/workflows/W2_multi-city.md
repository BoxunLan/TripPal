# W2 跨城市线路

> 命中信号：2 个以上相距较远的城市 + 天数（如"北京-西安-上海 10 天 9 晚"）。
> 底层逻辑：**一条线路 = 大交通骨架 + 逐段城市块 + 衔接细节。**

## 章节骨架

```
### 一、线路总览（为什么这样排、地理与时间关系）
### 二、城际大交通（高铁/飞机怎么串，哪段飞哪段高铁）
### 三、逐段展开：
        {城市 A}（Day 1–x）
        {城市 B}（Day x–y）
        {城市 C}（Day y–N）
### 四、城际衔接细节（换乘/行李/取票）      ← K07
### 五、住宿（每城住哪个区）                ← K06
### 六、餐饮与支付                          ← K09/K03
### 七、安全与应急                          ← K10
### 八、预算拆解（含城际大交通）            ← K11
### 九、检查清单
```

## 线路编排的四条通用原则

1. **减少折返**：地理上顺时针/直线串联，避免"南-北-南"。
2. **大交通用高铁优先**：城市群内（如长三角/成渝）高铁 1–2 小时，比飞机省时。
3. **首末城市 = 入境/出境口岸所在城市**，减少当天赶路。
4. **留缓冲**：机场/高原/支线航段留半天机动。

## 逐段展开写法

每个城市块 = 精简版 W1：**住哪 → 待几天 → 每天看什么 → 吃什么**。
不必像单城那样展开全部章节，重点写"这个城市在这条线上承担什么角色"。

## 常见变体

- 主题型线路（丝绸之路/大运河/高铁专题）→ 叠 W3，叙事按主题而非地理。
- 含特殊区域（西藏/新疆边境）→ 叠 W7 的证件/通行手续。
- 含高海拔（拉萨/九寨/香格里拉）→ 强加载 K12。
