# W5 入境实务操作（How-to）

> 命中信号："外国人如何……" 的单一动作（签证/绑外卡/买卡/订票/打车/导航/
> 订酒店/预约/点餐/就医/报警/防骗/退税/寄存/快递……）。
> 关键判定：**出现"如何"，即便句中有城市，也判 W5，不判 W1。**
> 底层逻辑：**一篇 how-to = 一条编号步骤流 + 失败应对 + 检查清单。**

## 章节骨架

```
### 第一步：先搞清楚——{为什么这件事有门槛 / 认知框架}
### 第二步：{准备什么 / 判定分支}
### 第三步 ~ 第 N 步：操作步骤（分渠道时用"渠道 A/B/C"）
### 常见错误与失败应对（表格：现象 / 原因 / 应对）
### 出发前 / 到达后检查清单
（可选）补充章节：场景成功率、红线与安全
```

## 写作要点

- **每步动词开头、可执行**，不给空话。
- **分渠道时用 A/B/C**（如高铁购票：官方 App / 线下窗口 / 第三方 OTA）。
- **失败应对是必备**：how-to 的价值一半在"搞不定时怎么办"。
- **判定分支**（如果 X 就 Y）：如"无中国手机号 → 走现金轨"。
- **给"最优路径 + 兜底路径"两条**，不假设用户设备/语言条件理想。

## 各 how-to 的隐藏判定分支（速查）

| 主题 | 关键分支 |
|---|---|
| 签证免签 | 免签 / 过境 / 普通签证（见 K01） |
| 绑定外卡 | 有中国手机号？停留 ≥ 7 天？（见 K03） |
| 买卡上网 | 停留天数 → 漫游 / 本地 SIM / eSIM（见 K04） |
| 订高铁票 | 官方 / 线下 / OTA（见 K07） |
| 订酒店 | 是否有涉外资质（见 K06） |
| 预约景点 | 有微信/中国号吗？抢不到怎么办（见 K08） |
| 点餐 | 有无英文菜单、忌口（见 K09） |
| 就医 | 轻症 / 重症（见 K10） |
| 退税 | 购物金额门槛 + 定点商店 + 凭证 |
