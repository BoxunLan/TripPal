# 外国人来华旅游攻略生成 Skill（Inbound Travel Planner）

> 一套面向「外国人来华旅游」场景的攻略生成引擎。输入一个旅行需求，
> 输出一份结构统一、信息可溯源、可直接执行的中文攻略文档。

---

## 1. 它解决什么问题

外国人到中国旅行，难点从来不是"没有攻略"，而是**攻略不贴合他们的真实处境**：
不会中文、没有中国手机号、只有外卡和护照、看不懂中文预约系统、对移动支付和
安检毫无预期。通用旅行攻略默认读者是"能读中文、能扫码、能用微信"的本地人，
一遇到"护照能不能预约故宫""外卡能不能刷地铁"就露馅。

本 Skill 专门站在**不会中文、无中国手机号、无中国 App 的外国游客**视角，
把每个环节拆成"可执行步骤 + 兜底方案"，并对所有时效性信息强制标注"需实时检索确认"，
**不编造票价、时刻、名单、开放时间**。

## 2. 适用场景

| 场景大类 | 举例 |
|---|---|
| 城市 / 区域行程 | 北京 5 天、上海 4 天含迪士尼、云南 7 天 |
| 跨城市线路 | 北京-西安-上海 10 天、丝路 14 天 |
| 主题深度游 | 美食、博物馆、古镇、徒步、摄影、非遗 |
| 人群细分 | 老年夫妇、亲子家庭、轮椅无障碍、素食 / 清真、数字游民 |
| 入境实务 | 签证免签、外卡绑卡、买卡上网、订高铁票、景点预约、就医报警 |
| 预算 / 季节 | 7 天 5000 元、国庆避坑、夏季避暑 |
| 特殊入境 | 邮轮、陆路口岸、转机 12 小时、带宠物 / 处方药 |
| 决策对比 | 北京 vs 上海、跟团 vs 自由行、高铁 vs 飞机 |

## 3. 核心设计：三层架构

```
意图层（workflows/ W1–W8）   决定"叙事骨架"   —— 泛化工作流
      ↑ 引用
知识层（knowledge/ K01–K12） 决定"事实内容"   —— 跨场景共享的原子能力模块
      ↑ 约束
契约层（contracts/）         决定"格式与质检" —— 输出模板 + 标注纪律
```

**设计哲学：工作流是泛化的，知识是共享的，场景是拼装的。**
一个"带轮椅的父母去西安 5 天"的需求 = 人群工作流骨架 × 单城行程骨架
＋ 无障碍/交通/住宿/预约四个知识模块 ＋ 输出契约约束。

- 换城市、换主题、换人群，**变的是工作流骨架的拼装方式，不变的是知识模块**。
- 时效性事实一律不写死在知识模块里，只给"查询方法 + 官方渠道"。

## 5. 使用流程

```
1. 解析用户输入 → 抽取 {地点, 天数, 人群, 主题, 预算, 季节, 入境方式, 对比项}
2. 按 SKILL.md 的路由决策树 → 确定 主工作流 + 修饰工作流
3. 打开对应 workflows/W*.md → 拿到该意图的章节骨架
4. 按骨架标注加载 3–5 个 knowledge/K*.md → 填充事实与操作细节
5. 需要速查数据时引用 reference/*.md
6. 按 contracts/output-contract.md 组装五段式 + 填 12 模块自查表 + 打标注
7. 过质检清单 → 输出
```

**判断意图的口诀：**
- 出现"如何……"→ 实务操作（W5），哪怕句中有城市。
- 出现"A vs B / 选哪个"→ 决策对比（W8）。
- 有城市 + 天数、无其他信号 → 单城（W1）或跨城（W2）。
- 人群 / 主题 / 预算 / 季节是**修饰**，叠在行程骨架上。

## 6. 输出质量标准（硬约束）

每一篇产出必须同时满足：

1. 严格五段式：`需求理解 / 完整攻略 / 信息覆盖自查表 / 需实时检索确认的事项 / 缺失项与需追问用户的信息`；
2. 12 模块自查表逐行填写，允许诚实标注"弱覆盖 / 不适用"，但不得留空；
3. 每条关键事实后缀 `[通用知识]` 或 `[需实时检索确认]`；
4. 所有时效性数字（票价、时刻、名单、开放时间、放票规则）只给"方法 + 官方渠道"，不编造；
5. 每个高风险环节都有兜底方案（找酒店前台 / 找游客中心 / 用现金 / 用翻译 App 截图）。

详见 `contracts/output-contract.md`。

## 7. 维护与更新

本 Skill 刻意**不缓存易变信息**，因此维护重点只有一处：**跟随官方口径更新"需实时检索项"的渠道**。

| 需关注 | 更新位置 |
|---|---|
| 免签 / 过境免签名单与天数 | `knowledge/K01_visa.md` |
| 外卡绑定规则与限额 | `knowledge/K03_payment.md` |
| 热门景点预约规则 | `knowledge/K08_attraction-booking.md` |
| 紧急号码 / 使领馆信息 | `reference/emergency-and-contacts.md` |
| 城市交通与必看清单 | `reference/city-quickref.md` |

**维护原则：只更新"渠道"和"判断逻辑"，不写入具体数字。**

---

## 8. 边界与免责

- 本 Skill 产出**方法论与操作路径**，不提供实时数据；具体票价、时刻、名单以官方实时为准。
- 不替代签证、医疗、法律等专业意见；涉及政策一律引导用户到官方渠道复核。
- 涉及网络访问合规、无人机、国际驾照、处方药、宠物等敏感事项，按中国法律法规如实提示。
