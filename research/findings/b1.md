> 切片：`research/buckets/b1.txt`（7 个文件，约 475 KB）。素材为 Stack Exchange API 的 JSON 抓取（`filter=withbody`），**仅含问题标题与问题正文，不含答案**；因此下文引文全部来自提问者的自述。
> 计数口径：**本切片内出现次数 = 切片内承载该痛点的独立问答（question_id）数**。同一问答会因 API 查询词重叠而同时出现在多个文件里（例如 Q192951 出现在 alipay / china-cash / china-payment / china-tag / china-votes 五个文件中），故不按文件数计数，以免重复放大。
> 来源标注：为便于溯回，每处证据给出**问题永久链接**（即该问答的规范来源）。各文件头部 `# source:` 为抓取用的 API 查询地址，如 `se-travel-alipay.txt` 的 `# source:` = `https://api.stackexchange.com/2.3/search/advanced?order=desc&sort=votes&q=alipay&site=travel&filter=withbody&pagesize=100`。
> 采集方式：以 Python 解析单行 JSON（文件为单行，grep 无法给出可用上下文），对正文做痛点关键词匹配后定点提取命中句。
