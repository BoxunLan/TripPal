# 叠加层：预算（budget）

在基座之上追加以下约束：

- **总花费不得超过用户预算的 110%**。分项必须写进 `budget.lines`，
  `category` 用固定分类之一：`交通` / `住宿` / `餐饮` / `门票` / `其他`。
- 给出至少 3 条明确的省钱动作，写进 `itinerary.suggestions`，
  例如：住青旅或民宿多人间、把跨城交通换成夜巴或慢车、用通票替代单次购票。
- 优先推荐免费或低价的替代点（城市公园、免费博物馆时段、步行街区、菜市场）。
- 避免：包车、单点付费导览、景区内二次消费项目、机场快线等高价交通。
- 若某分项明显拉高总额，主动替换为知识库中已有的低价同类项，并在 `notes` 里说明替换理由。
- 每日人均预算写进 `notes`，便于用户核对。
